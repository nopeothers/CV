# CV
Проекты для резюме.

Первый проект.
Это учебный проект по анализу веб-трафика и выявлению угроз. Система принимает на вход HTTP-логи, фильтрует их, анализирует и классифицирует запросы по типам атак.
Проект состоит из двух частей:
- Python-скрипты — фильтрация и классификация угроз
- SQL-запросы — хранение и анализ результатов

sqli_detector.py
Что делает: Детектирует SQL-инъекции в тексте.
- Белый список — нормальные домены (google.com, yandex.ru и т.д.)
- Сильные признаки (достаточно одного): SELECT, UNION, DROP, SLEEP(), комментарии --, /* */
- Слабые признаки (нужно 2+): кавычки, 1=1, OR 1=1

xss_detector.py
Что делает: Детектирует XSS-атаки.
- Критические признаки (достаточно одного): <script>, javascript:, onerror=, eval(), prompt()
- Опасные теги (<img>, <svg>, <div>) + обработчик события или функция
- Опасные функции (alert(), console.log()) + тег или обработчик

phishing_detector.py
Что делает: Детектирует фишинговые ссылки.
- Белый список — нормальные домены
- Высокодоверительные признаки (достаточно одного): g00gle, faceb00k, IP-адреса
- Низкодоверительные признаки (нужно 2+): подозрительные домены (.tk, .ml, .xyz), слова login, verify, password

classifier.py
Что делает: Главный классификатор. Объединяет все детекторы.
- Принимает JSON-файл с запросами
- Для каждого запроса вызывает детекторы по очереди:
Phishing → PHISHING
SQLi → SQLI
XSS → XSS
Ничего не найдено → NORMAL
- Выводит статистику по типам атак
- Сохраняет результат в JSON

create_tables.sql
- Создаёт таблицы для хранения результатов классификации:
requests — запросы с классификацией
classifications — типы классификаций


analysis.sql
Аналитические запросы:
- Подсчёт запросов по типам (GROUP BY)
- Топ-10 самых частых URL
- Поиск всех атак (кроме NORMAL)
- Поиск фишинговых доменов
- Статистика с процентами

Запуск
1. Фильтрация статики
python3 filter.py input.json filtered.json
2. Классификация угроз
python3 classifier.py filtered.json results.json
